# Papinoice Management System

## Run
1. Open Terminal in this folder.
2. Run `npm install`
3. Run `npm start`
4. Open **http://localhost:3000** in Safari/Chrome.

Do not open HTML files directly and do not use Live Server.

## Login
Admin: admin / admin123
Billing: billing / billing123
Stock: stock / stock123

Billing deducts stock automatically. Inventory uses 1 box = 24 sticks. Data is stored in data/db.json.
